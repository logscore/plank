---
title: Environment Variables
description: Full reference of Plank environment variables.
---

All environment variables are set in the `.env` file at the root of the project. Copy `.env.example` to `.env` to get started. Dev variables are commented out.

## Core

| Variable | Description | Default |
|---|---|---|
| `PORT` | Port the server listens on | `3300` |

## Authentication

| Variable | Description | Default |
|---|---|---|
| `BETTER_AUTH_SECRET` | Secret key used for session encryption. Use a random 32+ character string. | (none) |
| `BETTER_AUTH_URL` | Base URL of your Plank instance | `http://localhost:3300` |

## TMDB

| Variable | Description | Default |
|---|---|---|
| `TMDB_API_KEY` | API key for The Movie Database. Get one at [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api). | (none) |

## Prowlarr

| Variable | Description | Default |
|---|---|---|
| `PROWLARR_URL` | URL of your Prowlarr instance | `http://localhost:9696` |
| `PROWLARR_API_KEY` | Prowlarr API key. Auto-configured in Docker -- leave blank. | (none) |

## OpenSubtitles

| Variable | Description | Default |
|---|---|---|
| `OPENSUBTITLES_API_KEY` | API key from [opensubtitles.com/consumers](https://www.opensubtitles.com/consumers) | (none) |
| `OPENSUBTITLES_USERNAME` | Your OpenSubtitles username | (none) |
| `OPENSUBTITLES_PASSWORD` | Your OpenSubtitles password | (none) |

## Docker-Only

| Variable | Description | Default |
|---|---|---|
| `HOST` | Bind address. Leave as is if exposing publicly | `0.0.0.0` |
| `ORIGIN` | Public URL for CSRF protection. Set to your real URL if exposing publicly. | `http://localhost:3300` |
| `PROWLARR_CONFIG_PATH` | Path to Prowlarr config inside the container | `/prowlarr-config/config.xml` |
| `FLARESOLVERR_URL` | FlareSolverr URL | `http://flaresolverr:8191` |
| `STORAGE_SOURCE` | Optional host folder for saved files, replacing the default `/app/data` volume mount | `plank-data` Docker volume |

Leave `STORAGE_SOURCE` unset or blank for the persistent `plank-data` Docker volume. Set it to an absolute host folder such as `/mnt/storage` to use that folder instead.

See [Using Plank with Remote Storage](/guides/remote-storage/) for S3-backed filesystem setup guides.

SQLite and media processing stay on local storage. Switching `STORAGE_SOURCE` does not move files automatically. We do not support automatic migrations yet.
